# fuzzy1337.native_web_worker

Internal first-party worker for an explicitly governed finite response check.
The canary profile enforces its literal-loopback and closed path/query boundary
before opening a socket; default Git invocation remains compatible.
Its direct invocation does not establish consent. HTTP bodies/header values stay
transient; stdout contains only a bounded fixed execution report. The workflow
owns authorization, cancellation, evidence and model persistence.

::: fuzzy1337.native_web_worker
