# fuzzy1337.intelligence_cwe_remote

Experimental selected-CWE HTTPS source and custody SDK. Fixed versioned source
URLs, explicit digest/notice, canonical bounded requests and original raw evidence
remain one independent family. Local import and legacy snapshot contracts are
unchanged.

Separate raw/envelope/receipt acknowledgements preserve lost-publication
uncertainty. Offline replay verifies original joins and reparses retained bytes
without network, publication or model mutation. Successful decoding does not
establish publisher authentication, target applicability, legal entitlement or
complete catalog coverage. Installed CLI and genuine HTTPS acceptance remain
separate from synthetic SDK verification.
