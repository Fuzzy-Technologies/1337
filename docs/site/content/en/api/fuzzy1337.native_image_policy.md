# Internal native image authority

The canonical artifact-policy owner exposes a separate native IMAGE branch.
Fixed read-authorized material, explicit SAFE permission and workflow approval
bind original VERSION/SCAN grants without changing synthetic contracts.

Persistent single-use reservations precede capture. A separate immutable binding
records the full actual request once before startup; repeated launch checks
require the live scratch identity. Post-capture checks authenticate the persistent
binding and original evidence after legitimate scratch cleanup.

See `docs/NATIVE_IMAGE_AUTHORITY.md` and ADR 0093. These APIs do not supply SDK/CLI
enrollment, provider authenticity, an operating-system sandbox or a current grant
from historical replay.
