# fuzzy1337.intelligence_epss_commands

Internal explicit `intel epss import|inspect` consumer of the separate bounded
local acquisition profile. Import requires caller-selected physical local bytes,
model/day, unique requested CVEs, source attribution and terms. Inspection
selects exact envelope/receipt manifests and revalidates the saved original gzip;
it cannot enlarge the retained selection or enter legacy snapshot dispatch.

JSON outcomes distinguish configuration, integrity and acquisition failures and
retain independent publication acknowledgements. Unmatched CVEs remain explicit;
source decimal assertions, model metadata and score clock remain separate from
risk interpretation. Successful import requires all original custody records
and confirmed acknowledgements. No remote collection, automatic matching,
Finding application, model save or publisher authentication is introduced.
