# fuzzy1337.nucleiscan

This Experimental schema-v1 workflow composes the optional reviewed Nuclei adapter,
explicit STANDARD policy and exact-plan confirmation, governed execution, owned
jobs, immutable evidence, canonical findings and durable shared model state.
See [Nuclei workflow](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/NUCLEI_WORKFLOW.md)
and ADR 0055. Planning verifies local material/version without target contact;
execution rereads authority and verifies material at launch and canonical Save.
