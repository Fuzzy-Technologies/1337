EvidenceRecord and caller-associated anonymous concrete GET RequestTemplate.
The existing workspace/evidence owners verify actual manifests and raw bytes;
lexical anchor candidates retain exact attribution, canonical target/request
identities and current per-URL scope membership without transport authentication,
browser visibility, acquisition outcomes, findings or execution authority.

`docs/CAPTURED_WEB.md` and ADR 0050 define whole-artifact lexical admission,
token-local attribute decoding, source/provenance/time guards, same-origin
query-free URI resolution, exact work/count limits and truthful partial results.
Pure projection composes complete existing request collections and attributed
`web.lexical-link` observations for the shared model. Existing object omission
cannot be discovered by the pure interface; callers supply every current
candidate Endpoint before applying its complete request-collection patch.
Result shapes are readable Experimental records; direct constructors, parser,
allocation facade and integrity helpers remain Internal.
