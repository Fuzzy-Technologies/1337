# fuzzy1337.native_web

Experimental version-1 first-party web check planning and execution through
existing STANDARD confirmation, governed jobs, evidence and canonical Findings.
See [Native web checks](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/NATIVE_WEB_CHECKS.md)
and ADRs 0086/0088/0103. Explicit `check_id` selects the closed owned-loopback canary
or Prometheus exposition profile; the default retains Git behavior. Planning is read-only; execution rechecks current authority at launch
and Save. Original worker-report verification does not reconstruct the transient
HTTP body. No external scanner binary is required.

::: fuzzy1337.native_web
