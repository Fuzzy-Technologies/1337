# fuzzy1337.adapters.page_capture

Experimental ADR 0052 adapter and finite records for one owned synthetic page.
`KnownSyntheticHtmlBody` requires the explicit closed reviewed fixture ID;
arbitrary caller body digests, file paths and default body selections are refused.
The immutable catalog fields describe exact admitted bytes and supply no consent.

`NativeLoopbackPageAdapter` declares the distinct SAFE
`http.synthetic-page-capture` capability of `native.loopback-page`, version `1`.
Health and preparation perform no network operation. Actual execution requires
the current explicit URL/IP scope and capability permission through the existing
policy/executor owners. Plain HTTP at exact literal `127.0.0.1` or `::1` is the
only transport profile. NativeHTTP version 1 remains unchanged.

Normalization validates canonical flat worker stdout, exact invocation and
terminal execution, bounded owning evidence and the closed response body. It
produces only one observed source response envelope. It creates no hosts,
ports, services, findings, connectivity or fetched-link claims. Internal parser
helpers are consistency boundaries, not alternate authorization/launch APIs.
ADR 0087 requires isolated imports for current prepared invocations and default
provider validation. Only pure normalization admits an exact historical launch
shape, retaining original argv/digests without enabling that old execution path.
