# Native configuration selection and internal prerequisites

These syntax-only selections describe one general UTF-8 Dockerfile or portable
flat Kubernetes `.yaml`/`.yml` source, independently of the native compatibility
specimen catalog. Construction validates path and name syntax without reading
selected files. Reserved scanner-control and rendering names remain refused.

The fixed VERSION recipe retains an unknown observed provider version. The SCAN
recipe describes config-only embedded-check arguments; it is not an executable
request or an accepted VERSION prerequisite. Selected-read consent and the
Linux x86_64 Trivy 0.75.0 executable pin do not grant execution authority.

`NativeConfigurationSelection` is the Experimental explicit argument type for the
native configuration SDK under ADR 0110. Its syntax-only construction remains
read-free and supplies no execution authority. Other constants, validators and
descriptive recipe factories in this module remain Internal. ADR 0109 defines
their separate prerequisite boundary; the governed workflow owns native provider
execution, SDK/CLI enrollment and model import.
