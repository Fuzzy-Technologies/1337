# fuzzy1337.configuration_evidence

Experimental original-record consumer for the closed reviewed synthetic Dockerfile
and Kubernetes SCAN family. `ConfigurationOperationCapture` retains original typed
SDK execution/request/stage facts and the actual collection window. Its exact
schema-one envelope contains original SDK schema-two metadata, without granting
current authority.

`VerifySyntheticConfigurationReplay` independently verifies four original immutable
owning acquisitions: stdout, stderr, receipt and selected source. It checks role
budgets, stored manifests and bytes, source identity, original factory grammar,
source family, provenance and chronology. Replay survives relocation without old
physical stage paths and retains successful or refused original facts. It supplies
no launch, renewal, current acceptance or model mutation.

`ApplyVerifiedSyntheticConfiguration` also requires the exact typed original capture
and canonical fresh current SDK acceptance before returning a pure model proposal.
The known closed wire produces content-addressed synthetic configuration ASSETs and
typed source-position Findings. Deterministic check/location fingerprints preserve
operator triage; absent detections do not resolve earlier Findings. Foreign source
identity collisions refuse atomically. Source snippets and private hints remain raw
only, and no native, image or running-workload association is inferred.

The exports in `__all__` are supported Experimental interfaces. Helpers are Internal.
Original retained source bytes remain governed by explicit selected-read consent.
Evidence hashes and historical physical observations are attribution, without
publisher authentication, current grants or native scanner acceptance.
