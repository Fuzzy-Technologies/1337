# fuzzy1337.journeys

This Experimental schema-v1 library validates finite hand-written browser/API
journey declarations and prepares existing scope membership evidence offline.
Immutable preparation retains the scenario content digest and exact scope revision.
Membership does not authorize an executor job. No browser, HTTP, workload, session,
or external-data operation occurs.

The supported surface and workload units are documented in `docs/JOURNEYS.md`.
Validation helpers remain Internal; existing exact `Target` identity and workspace/
scope binding are reused without a new Security Object Model schema.

::: fuzzy1337.journeys
