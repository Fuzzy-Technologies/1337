# fuzzy1337.artifact_policy

Experimental contract version 1 provides closed synthetic profile preparation,
same-store artifact plans/grants and per-run raw-result acceptance receipts.
The exports in `__all__` are supported Experimental interfaces; helpers remain
Internal. Native IDs are metadata-only and cannot authorize or launch. Synthetic
launch requires the current trusted CPython runtime and closed reviewed producer
bytes. Fresh current authority/material is required at launch and acceptance;
historical replay grants nothing. Post-run refusal retains actual raw process
facts. This API does not establish authenticated principals or OS isolation.

The reviewed closed configuration family admits only synthetic Dockerfile or
Kubernetes SCAN with exact source/material bindings, SAFE approval and 16 KiB
stream ceilings. Configuration VERSION and image-proof substitution are refused;
native configuration and model interpretation remain separate. See ADR 0059 in
the repository for the exact five-case profile.

New execution metadata is schema 2. The closed richer image family adds separate
VERSION/SCAN requests, immutable `ArtifactVersionProof` and original prerequisite
bindings at planning, issuance, launch and final pair acceptance. Original schema-1
captures retain strict read-only verification with their original field shapes and
hashes; they never become current grants or VERSION evidence.

`VerifySyntheticImagePayloadReplay` adds pure richer-image schema-2 validation of
original detached request/stage payload bindings and closed factory grammar.
It preserves original path flavor and recorded platform values without current
filesystem, environment, interpreter or authority lookup. Raw stream verification
and consumer evidence/pairing remain separate. Saved physical observations and
material hashes are attribution rather than publisher authentication.

See [Governed local artifacts](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/ARTIFACTS.md).
