# Internal original local Docker material observations

LocalImageMaterialObserver observes the explicitly selected executable, physical Unix
socket and owning workspace. Issuer-retained object identity and current file/socket
facts cannot be reconstructed from equal serialized values. Native material
observation supports Linux only and refuses an unsupported runtime before selected
filesystem I/O. Deterministic portable test projections are logical tests, not daemon
or native process acceptance.

See `docs/LOCAL_IMAGE_REFERENCE.md` and ADR 0114.
