# fuzzy1337.intelligence_cvss2

Experimental read-only CVSS 2 inspection preserves the unchanged source-bound
intelligence snapshot, original CNA/ADP and metric-array positions, complete
provider/scenario context, and asserted source scores. Consumed vector grammar,
numeric bounds and explicit vector/field agreement are validated. Scores are
never calculated, rounded or converted; the profile makes no applicability
verdict, Finding mutation, network request or publisher-authentication claim.

`docs/INTELLIGENCE_CVSS2.md` and ADR 0104 define the source contract, finite bounds,
inspection result and unchanged schema-one snapshot/replay behavior.

::: fuzzy1337.intelligence_cvss2
