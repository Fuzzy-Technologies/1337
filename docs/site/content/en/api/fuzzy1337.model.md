# fuzzy1337.model

This Experimental schema-v1 foundation owns provider-neutral security objects,
typed relations, immutable observations, deterministic identities, incremental
deltas, and portable model persistence for an existing workspace.

`ModelState.ApplyAdapterResult` requires explicit first-party identity bindings and
provenance matching the executor-owned report. Scope and target references remain
opaque context; they never grant authority. Updates preserve attribution history.

The supported surface is documented in `docs/SECURITY_MODEL.md`; implementation
helpers remain Internal. This foundation does not infer reachability or risk.

::: fuzzy1337.model
