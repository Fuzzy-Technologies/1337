# fuzzy1337.business_events

This Experimental profile-v1 library preserves owner-defined unacceptable
outcomes as declarations over the existing canonical model. It adds no Core
object kind or persisted schema. `ReadBusinessEventDefinition` verifies bounded
original definition bytes, manifest provenance, explicit critical Asset members
and the exact current persisted model pin through the existing storage owners.

`ApplyBusinessEvent` returns an immutable model transition for caller-owned CAS
persistence. A dedicated Asset represents the declaration; attributed `RELATED_TO`
memberships describe declared impact without becoming technical transitions.
Exact original-manifest replay is idempotent. Existing findings, triage and
observation history remain unchanged.

`AnalyzeBusinessEventPaths` uses an existing verified technical projection and
explicit attacker positions. It retains each original path-analysis query to a
critical Asset and a separate descriptive outcome membership. Individual hop
states, estimates, source evidence, selected-subgraph scope and search/cut
truncation remain explicit. No incident, financial score, aggregate confidence,
execution permission or measured mitigation effectiveness is inferred.

ADR 0071 and `docs/BUSINESS_EVENTS.md` define declaration identity, provenance,
resource ceilings and failure behavior. Result constructors and helper functions
are Internal; pure application and analysis perform no implicit I/O.
