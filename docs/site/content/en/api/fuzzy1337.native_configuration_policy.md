# Internal native configuration authority

The canonical artifact policy engine owns domain-separated native configuration
plans, original grants, persistent one-use operation/observation claims and exact
full-request bindings. Current scope, selected target, owner, operator permission,
SAFE approval and original observer-issued material proof remain independent
requirements. SCAN additionally requires the exact original accepted VERSION
association from the same engine and pair.

Image grants, synthetic grants, copied receipts and historical replay cannot
acquire these original associations. Current authority is checked at both owned
process launch checkpoints and before fresh model application. See ADR 0110.
