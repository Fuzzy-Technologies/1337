# fuzzy1337.command_registry

The `paths` descriptor advertises Experimental version-one `paths analyze` over
one explicit pinned saved-model source/target selection and original reachability
proof. Discovery supplies no workspace, full model pin, selected references,
assessment manifests, attribution, replay clock, freshness, search/cut budgets or
authority. The Internal owner retains the existing whole-model node ceiling,
original UNKNOWN/confidence semantics and independent completeness results.
Registry presence creates no graph edge, acquisition, write, score or grant.

The `sbom` descriptor advertises Experimental version-one owned offline
`sbom import spdx-graph`. Discovery supplies no source path, original manifest,
source attribution, image digest kind, scope/run, revision basis or read consent.
The Internal handler owns acquisition, preserved custody and independent saves;
registry presence grants no scanner, retrieval or execution authority.

The `api` descriptor advertises Experimental version-one
`api import graphql-introspection`. Discovery metadata supplies no endpoint, source,
scope, consent, revision basis or transport authority. The Internal handler owns
original-file acquisition or known original-custody replay through existing stores;
registry discovery performs no import, preview, target registration or execution.

The `trace` descriptor advertises Experimental version-one explicit local
`trace ioc import|inspect`. Metadata supplies no selected file, source attribution,
receipt anchor, read consent, workspace context or execution authority. The
Internal handler owns bounded original acquisition and independently anchored
read-only replay; registry discovery creates no Core state or candidate facts.

The `runtime` descriptor advertises Experimental version-one owned offline
`runtime import <docker-inspect|kubernetes-list>`. Docker requires explicit `--host`;
Kubernetes requires explicit `--cluster` with an existing declared cluster ASSET.
Discovery metadata supplies no source path,
anchor, revision basis, read consent or daemon/cluster/execution authority. Command parsing
and storage remain with the Internal runtime implementation.

The `ci` descriptor advertises explicit current-run finding predicates and report
exports for caller-selected `synthetic-dockerfile`, `synthetic-kubernetes` and
`synthetic-image` profiles. Discovery metadata does not supply policy,
completeness, source/archive selection, SAFE opt-in or consent.

The canonical command registry includes `intel` for explicit local intelligence
import, verified inspection and selected Finding enrichment. Registry presence
does not authorize remote reads or execution.

The `scan` descriptor also exposes explicit closed synthetic image and configuration
workflows. Metadata does not select source files, material, runtime or consent.

The report descriptor advertises the four supported JSON, SARIF, HTML and JUnit
formats without selecting a source workspace or output path.
