# Internal original-response SDK workflow

The SDK plans without target contact, requires explicit SAFE approval and current
source authority for acquisition, and coordinates original custody with model and
workspace revision checks. Its model projection contains source facts and a stable
Endpoint; it creates no security Finding or assessment claim.

The selected actor is caller attribution. A supplied trusted owner provider can
refresh that attribution independently of the source consent attester. Historical
replay consumes verified originals without current execution authority or writes.
See `docs/OWNED_RESPONSE_CAPTURE_CONTRACT.md`.
