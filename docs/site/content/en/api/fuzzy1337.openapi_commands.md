# fuzzy1337.openapi_commands

Internal implementation of Experimental version-one `api import openapi-json`
through the installed console and foreground shell. All functions and helpers
remain Internal; use the documented product command rather than importing them
as a supported SDK. The existing `fuzzy1337.openapi` SDK remains separate.

The closed profile accepts an explicitly owned original JSON file or exact known
original acquisition manifest, an optional canonical base context and explicit
scope/run/current model/workspace revisions. Every imported operation must have
a concrete endpoint path and current exact scope membership. It creates no
transport, session, target registration, preview, Finding or execution permission.

Original bytes retain their complete digest and evidence provenance. Per-endpoint
custody binds the entire operation collection and exact resolution choice; replay
requires that known original context. Shared bounded preflights cover both API
profiles before generic reads. Existing model/workspace owners retain unrelated
operator data, refuse incompatible occupied collections and report independent
confirmed or unknown storage outcomes. See
[OpenAPI product import](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/OPENAPI.md)
and ADR 0089.
