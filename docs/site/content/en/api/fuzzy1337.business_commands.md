# fuzzy1337.business_commands

Internal console and shell transport for one already retained business-event
declaration under [ADR 0071](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/adr/0071-declared-business-event-profiles.md).

Use the documented
[business inspection command](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/BUSINESS_EVENTS.md#inspect-a-retained-declaration-through-the-product).
The explicit original manifest, scope attribution and complete model pin select
one persisted owner scenario and its saved critical Assets. Existing canonical
model records and original provenance remain authoritative.

`BusinessParser`, `InspectBusinessEvent` and `RunBusinessCommands` are Internal
implementation helpers, not a supported Python SDK. Inspection verifies the
original declaration, exact persisted memberships and selected evidence bytes
before terminal output. It creates no model/evidence state, technical paths,
priority result or incident assertion.

::: fuzzy1337.business_commands
