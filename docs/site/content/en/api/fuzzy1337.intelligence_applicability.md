# fuzzy1337.intelligence_applicability

Experimental read-only CVE 5.2 product-declaration inspection preserves the
original source-bound intelligence snapshot, separate CNA/ADP providers, source
array order, version ranges, status changes, and explicit uncertainty. It performs
no product matching, applicability verdict, score calculation, publisher
authentication, network access, or finding mutation.

`docs/INTELLIGENCE_APPLICABILITY.md` and ADR 0100 define the source declarations,
resource bounds, inspection profile, and compatibility boundaries.

::: fuzzy1337.intelligence_applicability
