# fuzzy1337.image_evidence

This Internal producer helper packages actual original artifact outcome,
prepared request, physical stage and observed collection window into
`ImageOperationCapture`. Its detached schema-one envelope contains the original
schema-two SDK metadata and exact payloads expected by the canonical
`fuzzy1337.synthetic_images` consumer. `Provenance()` attributes each captured
stream and receipt to that operation's actual invocation/execution.

Construction validates typed original objects and increasing clock readings.
Serialization preserves original source facts without retaining mutable caller
aliases. This helper performs no filesystem inspection, record verification,
execution authorization, interpretation, model application or persistence.
The canonical consumer owns six-role verification, historical replay and the
fresh paired acceptance boundary. Governed orchestration and durable saves
belong to `fuzzy1337.image_workflow`.

See [Closed synthetic image workflow](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/IMAGE_WORKFLOW.md).
