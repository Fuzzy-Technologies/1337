# fuzzy1337.image_evidence

Internal codecs and quotas verify the exact six-role original synthetic image
capture bundle. Actual owner-decoded manifests are role/media/size bounded before
eager blob reads. Schema-1 capture envelopes contain original schema-2 SDK facts,
exact detached prepared/stage payloads and observed collection windows. Original
request/grant/prerequisite/stream bindings are checked through the SDK replay
codec, retaining both operations' exact facts. This read-only module grants no
authority, launches no process and applies/saves no model.
