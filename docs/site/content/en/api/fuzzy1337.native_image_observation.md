# Internal bounded native image observation

The fixed observation owner issues instance-bound proofs for four explicitly
read-authorized native material roles. Its cumulative ledger accounts for three
observation windows and one shared finalization allowance. Current-proof checks
perform bounded physical metadata checks without reopening selected contents.

See `docs/NATIVE_IMAGE_OBSERVATION.md` and ADR0094 for deadlines, private custody
and the boundary before native product enrollment.
