# fuzzy1337.retained_report_ci

Internal bundle publication for the copyable opt-in retained GitLab/GitHub
examples. The installed owner invokes the existing JSON/JUnit report CLI, checks
original successful receipts, matching snapshot/verification identity and bounded
regular output bytes, then rechecks both reports and receipts before publishing
one complete CI-owned directory. It retires older selected output before source
validation and preserves original command failure/interruption statuses.

The module adds no supported Python SDK, installed console entry point, report
schema, finding gate, acquisition or remote operation. The GitHub sample only
uploads the completed artifact; its original hosted acknowledgements are separate
from local export receipts. GitLab retains its existing hidden job, source input
and artifact selection. Platform bootstraps also retire output before importing
this module so a missing installed helper cannot expose stale selected reports.

::: fuzzy1337.retained_report_ci
