# Same-basis selected-path comparison

Internal comparison and presentation helpers consume two completed original
`paths analyze` outcomes and the same exact owner-read saved model. They do not
admit serialized graph input or replace original proof admission. Common model
identity/revision/content, context, scope, clock, freshness, selected transitions,
endpoints and search/cut budgets must agree.

Only the explicitly selected focus transition may differ in its observed state
label. Zero changed labels is a valid completed pair; another transition-state
change refuses this finite profile. Both complete detached original outcomes
retain their proof references, confidence facts, reasons and independent search
and cut completeness. Equal labels do not imply equal evidence or other facts.
Before/after are caller-selected presentation roles, without chronology,
causality, a single changed control or remediation-effectiveness guarantees.
UNKNOWN stays attributed unknown; counts do not become probability or benefit.

Each original outcome remains bounded to one MiB including its newline. The
separate paired JSON ceiling is three MiB including its newline. Both sides use
the existing presentation bounds of 64 selected nodes and 128 transitions.
Comparison HTML is bounded to eight MiB UTF-8; these ceilings do not enlarge
ordinary analysis or the four-MiB single-state renderer.

HTML reuses the original static SVG producer through isolated data images and
escapes both complete original proof panels. Downloads retain exact comparison
JSON and both original SVGs. A restrictive CSP excludes scripts, external
resources, frames, forms and base URLs; the comparison introduces no JavaScript.
No model, workspace or evidence write, collection, network request or execution
authority is introduced. These helpers remain Internal; ADR 0132 defines the
additive Experimental product route.
