# Explicit path-state comparison commands

Internal implementation of Experimental `1337 paths compare`, product profile
version one. The caller pins one existing workspace/model revision and content
digest, source, target, selected transitions, focus, context, scope, analysis
clock, freshness and every search/cut budget. Each side explicitly supplies its
own original assessment manifests or chooses no assessments. There is no
discovery, alternate model, serialized graph input or arbitrary argument
forwarding. Repeated scalar flags, abbreviations and conflicting formats refuse.

Generated finite `analyze` requests call the unchanged owning `RunPathCommands`
sequentially. Each side must complete successfully through the original model,
evidence, support, projection and analysis owners. Captured machine output is
bounded before retaining another write. A failed side cannot produce a
successful first-only pair or partial HTML. The same actual workspace and model
are reread after both analyses and presentation; changed basis refuses success.

The comparison permits zero or one observed state-label difference, only at the
selected focus. Both complete original outcomes retain their own proof,
confidence, reasons, limits and completeness. Presentation roles do not establish
chronology, causality, remediation efficacy or measured access. UNKNOWN never
becomes zero risk, and structural counts remain selected symbolic-graph facts.

Output goes to the caller's stream as concise text, bounded version-one paired
JSON or static offline HTML. No hidden artifact file is created. JSON and HTML
are mutually exclusive. Exit zero includes honest truncation and no observed
state change; two means configuration refusal, four means basis/proof/profile/
output failure and 130 means interruption. Help reads no owning local state.
No saved model/workspace/evidence mutation, scanner, provider, daemon, network
operation or new execution authority is introduced.
