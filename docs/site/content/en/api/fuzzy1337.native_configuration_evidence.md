# Native configuration replay and internal model proposals

Read-only replay verifies the seven original owning acquisitions, fixed native
factory, request/grant bindings, stream/event identities, chronology, exact
source digest and original VERSION/SCAN association. It works after workspace
relocation without reopening original selected paths or reviving authority.
`NativeConfigurationReplay` and `VerifyNativeConfigurationReplay` are Experimental
read-only historical interfaces at native capture schema 1. Other interpretation
and fresh model-application helpers in this module remain Internal.

Fresh canonical proposals additionally require original live engine/claim/capture
identity and current same-stage material and scope/policy. Failed native rows map
to lowercase namespaced Finding check IDs; exact native IDs and supplied source
coordinates remain in location JSON and original provider evidence. See ADR 0110.
