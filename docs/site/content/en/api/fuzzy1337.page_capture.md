# fuzzy1337.page_capture

Experimental ADR 0052 `LocalPageCaptureProvider` connects the actual policy,
governed executor, packaged worker, ScanJob, evidence, captured HTML frontier,
structural requests and durable Security Object Model. Its consumer owns an
existing physical workspace/model, explicitly consented exact URL/IP scope and
distinct capability permission. No automatic CLI/shell/registry registration or
arbitrary-body crawler is introduced.

One job acquires one exact anonymous source GET. It verifies the actual terminal
process result and canonical closed record before evidence publication. Both the
stdout record and decoded admitted body use unchanged owner manifests/attachments
and role-specific bounded Get/Read verification. The existing captured-web
consumer returns lexical candidates; these links are never fetched by this plan.

The provider unions every existing source/candidate request collection, preserves
unrelated attributes/history and commits source response plus lexical projections
in one model Apply/Save before MODEL_DELTA and progress. Full scope snapshot and
revision remain pinned to launch. Policy and frontier hashes retain their distinct
owning serializers, including valid Unicode metadata with unequal hash strings.
After evidence/model composition, fresh consent/expiry and both exact URL/IP
memberships are checked immediately before owner Save.

Evidence survives later failure. A pre-Save failure does not save the proposed
model; optimistic conflicts are explicit. An ambiguous Save acknowledgement uses
owner reopen to report known committed, known uncommitted or uncertain state.
Cancellation/event failure after commit retains the persisted model and actual
worker success even when no model delta is delivered. Cross-store atomicity and
continuous revocation are not claimed.
