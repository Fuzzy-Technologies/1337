# Attributed offline reachability

Experimental version-one current-model proof verification, explicit transition
projection and pure bounded candidate-path search. Existing workspace/model and
evidence owners verify the pinned basis and raw artifacts; source attestations
retain their exact estimates, observations and manifests without source
authentication, automatic inference or execution authority.

`docs/REACHABILITY.md` and ADR 0047 define strict proof/context/time admission,
inclusive confidence bands, named barriers, conservative conflict handling and
truthful selected-subgraph truncation/no-path semantics. CONFIRMED is a supplied
hop attestation and an attested-hop-summary, not end-to-end exploit validation.
Direct result constructors, parsing and integrity helpers remain Internal.
