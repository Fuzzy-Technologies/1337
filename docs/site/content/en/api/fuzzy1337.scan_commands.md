# fuzzy1337.scan_commands

Explicit workspace, scope, foreground Quick Scan, exact-confirmed Nuclei and closed
synthetic image and configuration commands share the existing authoritative stores. Commands never
infer consent from registration, model state or a selected shell object. See
ADR 0037, ADR 0056, ADR 0072 and the Quick Scan, image and configuration workflow guides.

`scan config --profile synthetic` selects Dockerfile or Kubernetes input explicitly
and delegates to the existing governed configuration workflow. The five closed
source/material cases retain current authority checks, original four-role evidence,
durable state, terminal outcomes and separately requested JSON/SARIF exports.
This Internal command adapter adds no native scanner profile or execution grant.
