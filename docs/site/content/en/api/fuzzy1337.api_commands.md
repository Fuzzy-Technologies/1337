# fuzzy1337.api_commands

The API dispatcher also routes the explicit `openapi-json` product profile to
Internal `fuzzy1337.openapi_commands`. Both routes share bounded original-file
acquisition and preflight each other's retained custody before generic evidence
reads. Existing GraphQL defaults and original-custody bindings remain unchanged.

The installed CLI and foreground shell expose Experimental contract-version-one
`api import graphql-introspection`. This module is their Internal implementation:
all classes, methods, functions and helpers, including `ApiParser`,
`RunApiCommands`, `ApiEvidenceStore`, `RequireApiRecord`, `ReadOwnedGraphQl`,
`ApiSourceFact`, `AdmitApiProjection`, `PreflightApiReferences` and
`PreflightKnownApiReferences`, remain Internal. Visibility does not establish a
supported Python SDK.

The closed profile requires an existing explicit workspace/model, concrete
query-free HTTP(S) endpoint, scope, run and independent current model/workspace
revisions. Existing consent, exact endpoint registration and allow/deny rules
must admit current membership before original source reads. Source contents and
shell context supply none of these selections. Membership is not permission to
execute a query, mutation or subscription; no scope, target registration, session
or execution grant is created or changed.

Original-file selection requires explicit artifact-read actor/consent references.
These declarations are not verified signatures or endpoint assessment authority.
The physical regular file must be singly linked and within the unchanged SDK's
512 KiB ceiling. Observed path/handle device/inode/size/mtime/ctime identities
remain equal within each view; the existing Windows cross-view ctime allowance
never permits a same-view change. Reads are bounded and never acquire truncated
input. These guards do not claim hostile-writer filesystem isolation.

The existing evidence owner retains original unredacted JSON bytes, including
descriptions/default literals that symbolic normalization excludes. Malformed or
unsupported input may remain acquired evidence after normalization refusal.
Select an owned source appropriate for that retention. Original file acquisition
observes its own receiver clock; summaries omit source contents and physical paths.

Retained selection requires the exact original manifest identity, fixed
`graphql-introspection` JSON role, finite size, workspace/scope/source/version
bindings and absent execution/invocation provenance. Its known original
`api-import-source` custody must agree with the same endpoint, run, scope and
original read references before raw access. A source digest alone cannot establish
that custody, and a bare compatible SDK manifest is refused. Retained replay
accepts no read-attribution overrides and performs no new acquisition. Original
manifest verification and raw-byte reimport survive workspace relocation and
external source-file removal.

Before generic workspace/report verification in either selection mode, preflight
checks known GraphQL manifest identities, original custody IDs and profile raw
references in workspace/model provenance. Fixed role/media, the 512 KiB ceiling
and physical length are checked without raw reads; incompatible references to the
same digest are refused. Each original manifest keeps its recorded scope. These
budget checks do not adopt custody or cap unrelated evidence below its own bounds.
`ApiEvidenceStore.CheckReference` remains an Internal preflight helper.

The controller calls unchanged `ImportGraphQl`, `CheckGraphQlTarget` and
`ProjectGraphQl`; it never invokes request-preview generation. Current membership
is checked again for every imported operation before mutation. An Endpoint can
receive its first API collection, or retain both exactly matching canonical
`request_templates` and `graphql_import` values. Partial/incompatible occupied
collections are refused before model write; general refresh and source composition
are absent. Unrelated attributes/provenance, triage and UNKNOWN facts retain their
existing model meanings. Structural operation descriptions do not create Findings.

Projection and the inert original-custody Observation share one model transition.
The selected model CAS is followed by an independent workspace CAS retaining its
model, scope and original evidence references. Schema-one terminal summaries expose
digests, counts, revisions and separate acquisition/model/workspace acknowledgements.
`confirmed` acknowledges that owner, `not-attempted` means its boundary was not
entered, `not-committed` records a known busy/revision refusal and `unknown` permits
an actual commit whose acknowledgement was lost. Later failures do not roll back
earlier commits; no cross-store atomic transaction is claimed. Exact retained
replay preserves stored bytes and can finish workspace references after an earlier
model commit. Reopen actual owners and select current revisions after uncertainty.

Exit `0` means verified success, `2` configuration refusal, `4` other failure and
`130` interruption. Generic diagnostics omit rejected argument values. SDK/Core,
request schemas and evidence receipts are unchanged. Introspection fetch, SDL or
traffic input, endpoint discovery, authentication, request previews and HTTP/native
execution are separate work; Task #145 and Feature #143 remain open.

See [GraphQL import](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/GRAPHQL_IMPORT.md)
and [ADR 0081](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/adr/0081-owned-offline-graphql-product-import.md).
