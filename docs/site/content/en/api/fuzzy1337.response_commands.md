# Internal original-response command boundary

The `response capture` command exposes explicit planning or approved acquisition
through the same SDK owners. `response replay` verifies an existing original
receipt offline. Policy and selected actor references remain explicit; no command
manufactures permission, accepts caller headers or treats captured source facts
as a security assessment.

See `docs/OWNED_RESPONSE_CAPTURE_CONTRACT.md`.
