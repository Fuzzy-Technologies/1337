# Internal intelligence receiver

This Internal standard-library worker receives the owning acquisition module's
explicitly selected HTTPS artifact. The parent validates the immutable source,
clears the environment, fixes finite byte/deadline limits and owns termination
and joining. The receiver refuses redirects, unsupported framing and encoding,
and streams only bounded original bytes with explicit terminal status.

Use the owning `fuzzy1337.intelligence_acquisition` API. These helpers are not a
general scanner, credential client, publisher-authentication API or independent
execution authorization boundary.
