# `fuzzy1337.intelligence_cwe_commands`

Internal local CWE CLI consumer over the unchanged Experimental custody SDK.
`RunCweIntelCommands` accepts only explicit local import and exact immutable-root
inspection after inherited top-level help/JSON normalization. It validates source,
IDs, scope and budget before file reads and both root syntaxes before storage.

`CweIntelParser`, `CweArguments` and `CweRoot` own forwarded grammar and preflight.
`CweCustodyComplete` requires real succeeded state, complete bytes, three confirmed
ACKs and every handle. `WriteCweMetadata` and `WriteCweDetails` present readable
source fields, full captured notices and distinct selected partitions.
`CweTerminalBuffer` and `CweTerminal` stage actual UTF-8 output within separate
finite human/JSON budgets; failures expose no usable selected assertions.
JSON uses lossless ASCII Unicode escapes and human text explicit backslash
escapes before byte accounting, including non-BMP expansion. Redirected strict
CP1252/ASCII streams preserve source facts without changing original bytes.

The terminal profile is `cwe-local-selected-cli`, schema one/profile one. Import
ACK basis is `sdk-returned`; inspection is `verified-present`, preserving the
historical distinction. Raw digest means the actual confirmed artifact, including
partial prefixes. No model write, remote receiver, source discovery, legal-rights,
authenticity, risk or applicability assessment is performed. Command examples are documented in `docs/CWE_LOCAL_CUSTODY.md`.
