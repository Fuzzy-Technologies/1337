# Internal original-header predicate

`HeaderFieldAbsent` is the internal pure version-1 predicate for complete verified
original header sections. It compares complete token field names case-insensitively
with `x-content-type-options`; body text, route labels and expected detector
outcomes are not inputs. Bounds and complete grammar failure raise
`NativeResponseHeaderError`, rather than producing a negative assessment.

Calling this function directly establishes no source custody, scope, permission,
Finding or persistence acknowledgement. Use the
[owning SDK](fuzzy1337.native_response_header_workflow.md), which binds the actual
original seven-role receipt and independent current PASSIVE admission. The
predicate checks field absence; it does not validate arbitrary field values or
assert general MIME-sniffing exploitability.
