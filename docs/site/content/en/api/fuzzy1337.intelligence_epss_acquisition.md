# fuzzy1337.intelligence_epss_acquisition

Experimental local acquisition and verified replay for the distinct selected-ID
EPSS gzip profile. Explicit caller attribution, model/day, terms and requested
CVE scope bind to original evidence manifests, a selected envelope and terminal
receipt using the existing workspace and evidence owners. The separate
`epss-acquired-selection:` identity nests the unchanged decoder profile; legacy
intelligence snapshot references and loaders remain unchanged.

Original source bytes are retained before parsing. Selection/receipt/raw roles,
media types and per-role limits are checked before content reads. Owner/importer
provenance and receipt/envelope joins are checked before interpreting JSON or
source assertions. Reopening verifies these exact joins, reparses
the complete original gzip and compares the entire selected result. Relocation
needs no original input file. A score clock after observed acquisition refuses.

Raw, selection and receipt publication acknowledgements are independent.
Unknown acknowledgement does not mean rollback; storage failure may leave
immutable records and cannot be reported as complete successful custody.
Caller declarations are retained without authenticating the publisher or
validating legal terms. There is no network acquisition, model mutation,
automatic matching, Finding application or legacy snapshot dispatch.
