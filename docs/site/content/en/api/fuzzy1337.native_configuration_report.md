# Internal native configuration report interpretation

Bounded schema-two native JSON interpretation requires exactly the selected
Dockerfile or already-rendered Kubernetes file and positive embedded-check loader
evidence. It preserves every original native check row, status, severity and
supplied coordinates without importing synthetic expectations. An empty result
or successful process alone does not prove selected-file processing.

This pure parser issues no execution grant, model transition or clean-configuration
claim. See `docs/NATIVE_CONFIGURATION.md`
and ADR 0110 for the owning SDK workflow and seven-role original custody.
