# fuzzy1337.adapters.native_web

Experimental version-1 finite first-party response-check adapter: Git HEAD and
the closed owned-loopback file-canary profile. The immutable check registry binds
each predicate to its capability and exact request profile.
Preparation grants no authority. It binds one exact selected URL and normalizes
only the original fixed worker execution report with matching provenance.
See [Native web checks](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/NATIVE_WEB_CHECKS.md).
