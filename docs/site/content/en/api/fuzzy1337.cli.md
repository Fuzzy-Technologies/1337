# fuzzy1337.cli

The Experimental version-one `paths analyze` route delegates to its Internal
read-only owner with exact saved-model revision/snapshot pins, explicit original
source/target/transitions and assessment manifests or `--no-assessments`, offline
context/scope, replay clock, freshness and finite search/cut budgets. The existing
whole-model 512-eligible-object ceiling is checked before proof reads. `--json`
preserves original UNKNOWN/reasons and declared versus effective confidence,
structural counts and separate search/cut completeness in a bounded explanation.
Static help reads no local state; dispatch grants no authority and writes no
Core/model/workspace/evidence or hidden output.

Experimental version-one `sbom import spdx-graph` imports an explicitly owned
offline original file or exact known original product manifest. The caller
selects source/read-consent attribution, image digest semantics, offline scope,
run and both current revision bases. The Internal handler preserves original
custody, all-known SBOM alias preflight and three independent acquisition/model/
workspace acknowledgements. Static help opens no local state; import grants no
scanner, remote retrieval, reachability or license-compliance authority.

The Experimental version-one `api import graphql-introspection` route imports one
explicit owned original file or known original evidence custody. Endpoint, current
scope, run and model/workspace revision bases remain caller-selected. The Internal
handler uses unchanged SDK/store owners, refuses incompatible occupied API
collections and reports acquisition/model/workspace acknowledgements separately.
It retains bounded original bytes unredacted and supplies no introspection fetch,
request preview, HTTP/native execution, Finding or execution grant.

The Experimental version-one `trace ioc import|inspect` route imports an explicitly
selected owned non-secret local file or verifies independently retained snapshot
and original receipt manifest identities. Source/version/license/hash/scope/read
references and finite budgets remain explicit; no dataset or source is inferred.
The unchanged IOC evidence owner retains original bytes while terminal summaries
show only counts, observed hashes and evidence identifiers. Neither action saves
Core/workspace state, probes targets or grants authority; the handler is Internal.

The Experimental version-one `runtime import docker-inspect` route imports one
explicit owned offline file or exact retained manifest using an existing literal
HOST, scope and caller-selected model/workspace revisions. New-file acquisition
requires explicit read-consent references. `--json` preserves independent
acquisition/model/workspace acknowledgements and partial failures; static runtime
help opens no local state. The owning handler and its helpers remain Internal.

`ci scan` dispatches an explicit selected-profile finding predicate and three
verified report exports. Satisfied/violated outcomes remain distinct from
invalid setup, authority refusal, integrity failure and cancellation.

The product CLI routes explicit local `intel import|inspect|apply` commands to
their owning evidence/model workflow. `--json` emits bounded terminal summaries;
command preparation grants no remote acquisition or automatic enrichment.
