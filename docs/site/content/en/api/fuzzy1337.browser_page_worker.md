# fuzzy1337.browser_page_worker

Internal isolated ADR 0090 worker for one governed owned acquisition and offline
Chromium render. Unchanged native Probe admission completes before optional
Playwright import or launch. The fixed offline about:blank context disables page
JavaScript and refuses requests, sockets, service workers, downloads and extra
pages. Only bounded DOM counts, size/digest and actual engine versions are returned.
Available original verified body custody survives renderer failure. The Linux
descendant owner must verify cleanup before terminal execution can complete.
