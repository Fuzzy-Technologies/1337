# fuzzy1337.discovery

Experimental native SAFE HTTP discovery producer, version 1, under ADR 0036.
The consumer creates a workspace/model and supplies current explicit URL/IP scope
consent, capability policy, job ownership and finite limits. One exact literal-IP
endpoint probe runs through the governed executor. Verified status-only evidence
precedes durable Host/Port/Service/Endpoint updates and live model delta events.
No DNS resolution, redirects, queries, credentials or response bodies are retained.
Failures and cancellation remain truthful; preparing a producer grants no authority.

::: fuzzy1337.discovery
