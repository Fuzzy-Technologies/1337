# fuzzy1337.path_rendering

This Internal module implements the Experimental `1337 paths analyze --html`
presentation profile. `RenderPathHtml`, `GraphSvg`, `Layout`, `EdgeGeometry`,
`Anchor`, `Download` and its fixed script/styles/limits are implementation details,
not a supported Python SDK or an alternate admission boundary.

The existing command verifies the exact saved model, original evidence and final
current basis before passing its successful bounded outcome to this pure
renderer. No I/O, graph inference, confidence composition or authority is added.
Only selected endpoints, their original model kinds and references, actual
transition states/reasons/proof attribution, returned paths and separate cut
results are presented. Arbitrary object attributes and raw evidence are excluded.

The profile admits at most 64 nodes and 128 transitions, refusing larger views
without implicit partitioning. The artifact is bounded to four MiB and contains
the exact schema-one ordinary JSON outcome and the same static SVG as downloads.
Existing JSON limits and output remain unchanged.

Original state words and line patterns, structural `CUT` markers, visible
uncertainty and independent search/cut completeness preserve the owner's meaning.
Fixed JavaScript adds pan/zoom/reset and keyboard-compatible inspection; the graph
and expandable text remain readable without scripts. HTML text/attributes and
inert JSON are escaped separately. Fixed download types/local anchors and a CSP
admitting only the exact script hash prevent source-controlled executable markup
or resource fetching. Genuine Chromium interaction and V8 block coverage are
required in the existing opt-in browser acceptance job.

This slice leaves canonical scenario integration, broader object families,
grouping and remediation before/after comparison open under #121. Structural cuts
are neither proof of physical access nor validated remediation efficacy.

See [product usage](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/PATHS_ANALYSIS.md)
and [ADR 0124](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/adr/0124-offline-selected-path-presentation.md).
