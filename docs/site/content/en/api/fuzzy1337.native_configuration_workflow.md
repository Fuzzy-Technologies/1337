# Native configuration SDK workflow

`PlanNativeConfigurationScan` previews one explicit selected source's exact
manifest target or describes current VERSION authority without executing Trivy.
`ScanNativeConfiguration` requires separate explicit SAFE approval and current
operator policy, then owns original VERSION/SCAN execution, seven-role evidence,
fresh native Finding proposals and one-attempt durable persistence.

Exact model and workspace save acknowledgements precede successful model-delta
events. JSON/SARIF export uses the acknowledged saved snapshot and exposes a
separate publication outcome. Unknown custody, missing permission, changed source,
unprocessed output and unconfirmed saves cannot become successful scan facts.
See ADR 0110 and `docs/NATIVE_CONFIGURATION.md` for source limits and CLI usage.
