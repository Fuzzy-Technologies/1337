# fuzzy1337.artifact_inputs

Experimental contract version 1 provides explicit selected-file read authority,
portable role/profile-separated manifests and bounded observed staging integrity.
The exports in `__all__` are the supported Experimental surface; other helpers
remain Internal. Input manifest identities reuse the existing scope store and are
distinct from file/OCI digests. Capture grants no execution authority and provides
no hostile-writer, OS sandbox or publisher authenticity guarantee.

See [Governed local artifacts](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/ARTIFACTS.md).
