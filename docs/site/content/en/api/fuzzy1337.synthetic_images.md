# fuzzy1337.synthetic_images

This Experimental contract verifies six original immutable acquisition records
for the closed synthetic image VERSION/SCAN family. `ApplyVerifiedSyntheticTrivyImages`
checks the exact original typed runs, derives its own evidence-linked provenance,
builds isolated candidates and calls the canonical artifact SDK's fresh paired
acceptance immediately before pure model/Finding application. It returns one
in-memory snapshot and aggregate delta; persistence and assembled workflows are
separate responsibilities.

`VerifySyntheticTrivyImageReplay` returns immutable `SyntheticImageReplay`
original attribution and refusal facts. It reads only the owning workspace's
retained records and bytes, verifies original schema-specific SDK metadata and
detached payloads, and checks the original pair. It inspects no current physical
stage, refreshes no authority and performs no launch, live application or save.
Both VERSION stderr and SCAN stderr remain original records when empty.

Every synthetic asset/reference and Finding check remains in the fixed fixture
namespace. Native image APIs, raw evidence and operator triage remain unchanged.
Neither valid byte attribution nor zero Findings proves genuine Trivy acceptance,
scanner completeness, publisher authentication or physical isolation.

::: fuzzy1337.synthetic_images
