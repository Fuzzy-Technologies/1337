# fuzzy1337.demo

Experimental schema-v1 command-owned localhost demo composition. It invokes the
ordinary workspace/scope/SAFE scan and saved-workspace report product interfaces,
retains actual events/acquisitions and owns target teardown. No artificial
Findings or graph state are constructed. See the
[demo guide](https://github.com/Fuzzy-Technologies/1337/blob/develop/docs/DEMO.md)
and ADR 0054. Existing scope/policy/evidence/model/report owners remain authoritative.

::: fuzzy1337.demo
