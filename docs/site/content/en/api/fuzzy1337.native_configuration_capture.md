# Internal native configuration original capture

The fixed collector executes separately granted original VERSION and SCAN
operations through Linux descendant ownership. It preserves bounded original
event fragments before continuation and binds terminal results, stream digests,
fresh post-operation material proof and confirmed cleanup to the exact request.
Both documented pre-launch checkpoints revalidate the same original authority.

Each operation retains original stdout, stderr and receipt through the canonical
evidence owner. Unknown terminal custody keeps private original controls and
cannot become successful capture or model authority. See ADR 0110.
