# Internal governed original-response acquisition

This first-party provider composes the existing policy, local executor and job
owners for one explicit SAFE acquisition. Its current-context closure checks the
whole fixed actual request as well as current original grant, owner and source
authority. Cancellation retains the existing awaited process-cleanup boundary.

Only admitted originals reach canonical evidence. Parent source, execution and
persistence acceptance are reviewed separately from the wire schema. See
`docs/OWNED_RESPONSE_CAPTURE_CONTRACT.md`.
