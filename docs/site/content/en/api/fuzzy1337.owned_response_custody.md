# Internal original-response evidence custody

This boundary admits the actual terminal result and original event fragments,
stages only approved non-secret originals and verifies canonical attachments by
their real returned IDs. The receipt follows verified predecessor attachments.
Partial publication preserves actual attachments and uncertainty without a
replacement Put or acknowledgement.

Historical replay verifies original manifests and bytes after relocation without
a target, current grant, process or new evidence. See
`docs/OWNED_RESPONSE_CAPTURE_CONTRACT.md`.

The low-level caller must supply an actually acknowledged original receipt ID.
Canonical storage verification alone does not establish a lost Put acknowledgement;
SDK replay also requires the persisted original source/job association.
