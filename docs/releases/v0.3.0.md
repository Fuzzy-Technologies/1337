## Digest

1337 Security Workbench v0.3.0 brings the experimental Community scanner workflows
into a reproducible installed package: explicit scope and approvals, governed
execution, retained evidence, saved workspaces and offline reports. Its supported
human, agent and CI entry paths share those contracts. This remains an early
product; individual capabilities and platform boundaries are stated explicitly.

## What's Changed

### Added

- Native discovery and selected web checks, Nmap/Nuclei adapters, image workflows
  and retained source-linked Findings through the documented interfaces.
- Durable workspaces and JSON, SARIF, HTML and JUnit report exports for reviewing
  actual results after execution ends.
- Clean-install release verification, same-byte wheel/sdist publication and
  Trusted Publishing attestations.

### Documentation

- [Quickstart](https://github.com/Fuzzy-Technologies/1337/blob/v0.3.0/docs/QUICKSTART.md),
  [agent entry](https://github.com/Fuzzy-Technologies/1337/blob/v0.3.0/docs/AGENT_QUICKSTART.md)
  and [CI scan](https://github.com/Fuzzy-Technologies/1337/blob/v0.3.0/docs/CI_SCAN.md).
- [Capability boundaries](https://github.com/Fuzzy-Technologies/1337/blob/v0.3.0/docs/COMPATIBILITY.md)
  and [security guidance](https://github.com/Fuzzy-Technologies/1337/blob/v0.3.0/SECURITY.md).

### Security

- Explicit source scope, independent approvals, fixed invocation/material
  identities, bounded process ownership and truthful partial outcomes remain
  mandatory. Discovery or zero Findings never establishes a clean target.

## Breaking Changes

No Stable contract break is intended. Experimental interfaces have grown since
v0.2.1; review the version-pinned compatibility and command documentation.

## Try it from source

```sh
git clone --branch v0.3.0 --depth 1 https://github.com/Fuzzy-Technologies/1337.git
cd 1337
python -m pip install uv==0.11.33
uv run --locked 1337 help
```

For an isolated installed CLI, use a clean virtual environment and the exact
published version:

```sh
python -m venv .venv
.venv/bin/python -m pip install 1337==0.3.0
.venv/bin/1337 --version
.venv/bin/1337 doctor
```

On Windows, use `.venv\Scripts\python.exe` and `.venv\Scripts\1337.exe`.
Read the quickstart before approving a scan; optional external tools are not
installed or authorized automatically.

## Notes

The package version is a final numeric `0.3.0`; early-product maturity is not a
Python prerelease suffix. Linux ownership-backed runtime paths and optional
provider requirements remain explicit. General authenticated DAST, unrestricted
SPA/API testing and complete application-wide scanner comparisons are not
claimed by these bounded capabilities. Consult the version-pinned documentation
for supported commands and known exclusions.
