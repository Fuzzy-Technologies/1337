# Code of Conduct

Be respectful, professional, and constructive.

Harassment, discrimination, threats, personal attacks, and deliberately disruptive behavior are not welcome in this project. Keep discussions relevant to the work and disagree with ideas rather than people.

Repository maintainers may moderate, edit, lock, or remove disruptive content and may restrict participation when necessary.

If you need to report a conduct problem, contact the repository maintainers privately through GitHub or use GitHub's reporting tools.
